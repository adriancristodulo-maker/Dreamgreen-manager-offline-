# Dream Green Manager v0.4

- Dashboard: de încasat, restanțe după scadență (roșu), total încasări.
- Termen de plată opțional pe fiecare lucrare; fără termen, suma este doar „de încasat”, nu restantă.
- Rapoarte: încasări ultima lună/3 luni, sume neîncasate pe lucrări și restanțe.
- Datele sunt afișate în format zz.ll.aaaa; câmpurile native iPhone de selectare a datei sunt controlate de iOS.
- Reducerea derulării laterale și a zoomului (atenție: dezactivarea zoomului reduce accesibilitatea).
- Logo transparent și pictograme noi.
- Restul funcțiilor v0.3 rămân.

Înainte de actualizare: exportă un backup. Încarcă fișierele din arhivă în rădăcina repository-ului existent. Nu șterge aplicația iPhone. Datele rămân în IndexedDB în același context de instalare.

Alertele interne se văd la deschiderea aplicației; nu există push notifications iOS.
